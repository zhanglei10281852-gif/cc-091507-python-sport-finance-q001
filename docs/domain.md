# 领域说明

赞助合同通常按里程碑分期付款，训练营、差旅和税费预留会消耗赛季预算。合同生效日、验收日、银行价值日和更正时间可能不同，记录需要同时保留业务发生顺序与接收顺序。金额精度、币种、退款和冻结余额属于长期留存的账本信息。

`reference/domain.json` 保存公开的合同事件、资金用途和币种枚举。正式流水应使用稳定标识，并区分业务时间、接收时间和版本。

## 账本模型

- 事件是唯一事实来源：`seq` 表达接收顺序，`business_date` 表达业务发生时间，
  `period` 是接收时确定的归属期间。业务月份已发布快照的迟到事件保留真实业务
  日期，但计入最近一个未冻结月份。
- 四本账按合同币种计量：承诺额（当前计划版本的分期合计）、已用额（支出与代扣
  扣除退款）、待验收款（已报验未验收的分期）、可支配余额（到账 − 消耗 ± 汇率
  调整）。每个数字都附 `basis`，可定位到组成它的流水或分期版本。
- 退款、冲正、汇率差额以独立流水记录，通过 `links` 指向原始流水；被冲正的
  流水标记 `reversed_by`，读取时可双向追溯。
